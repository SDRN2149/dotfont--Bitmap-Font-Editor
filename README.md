# DotFont v10 — Unicode Pixel Typeface Editor

Unicode 코드포인트를 중심으로 글리프를 만들고 TTF/OTF로 내보내는 브라우저 기반 픽셀 폰트 에디터입니다.

## 핵심 기능
- Basic Latin (A–Z / a–z), 숫자, 기호, Printable ASCII 프리셋
- 문자 또는 `U+0041` 형식으로 글리프 직접 추가
- `U+2500`–`U+257F`처럼 Unicode 범위 추가 (한 번에 최대 512개)
- PUA `U+E000`–`U+E00F` 빠른 추가
- 문자 / 코드포인트 검색
- 8×8, 12×12, 16×16 픽셀 편집
- 가이드, 실제 글자폭, 글리프별 자간, 최종 Advance 실시간 표시
- 글리프 복사/붙여넣기, 이동, 반전, 삭제
- 사용자 정의 ligature + GSUB `liga` 내장
- TTF / OTF export
- JSON 프로젝트 저장/불러오기
- favicon / PWA manifest 포함

## 실행
`index.html`을 브라우저에서 열면 됩니다.

## Unicode 입력 예
- `A` 또는 `U+0041` → A
- `U+00FE` → þ
- `U+2500` → ─
- `U+E000` → Private Use Area 글리프

## Ligature 예
- `fi` → `ﬁ` (`U+FB01`)
- `->` → `→` (`U+2192`)

TTF/OTF export는 처음 사용할 때 외부 모듈을 불러오기 위해 인터넷 연결이 필요할 수 있습니다.

## v10.2 — 삭제 UI 개선
- `지우기` → `내용 지우기`
  - 현재 글리프의 픽셀 디자인만 초기화
  - Unicode 글리프 슬롯은 유지
- `글리프 삭제` → `글리프 제거`
  - 프로젝트에서 해당 Unicode 슬롯 자체를 제거
- 글리프 제거 전 확인창 추가
  - 예: `U+0041 A 글리프를 프로젝트에서 제거할까요?`
- 확인창에서 취소하면 아무 것도 삭제되지 않음
- 실수로 제거한 기본 글리프는 ASCII/Latin 등 프리셋 버튼으로 다시 추가 가능


## v10.3 — 레이아웃 / 스크롤 개선
- 좌측 상단의 프리셋 버튼 제거
- 기본 로딩 글리프를 `라틴 알파벳 + 숫자 + 기본 기호/문장부호`로 확장
- 좌측 패널 하단에 글리프 세트 추가 버튼 배치
- 새 글리프 세트 버튼 추가
  - Latin-1 Supplement
  - Latin Extended-A
  - Latin Extended-B
- 글리프 목록 정렬 개선
  - A–Z → a–z → 숫자 → 기본 기호 → 확장 라틴 순서
- 좌측 패널 독립 스크롤
- 도트 입력 영역 독립 스크롤
- Properties 패널 독립 스크롤
- 긴 작업 중 좌우/중앙 패널을 따로 움직일 수 있게 개선


## v10.4 — 글리프 세트 버튼 / 도트판 크기 수정
- 하단 글리프 세트 버튼이 동작하지 않던 문제 수정
  - 누락되었던 `addGlyphSet()` 구현
  - Latin-1 / Latin Extended-A / Latin Extended-B 이벤트 연결
- 세트 버튼 클릭 시:
  - 누락된 글리프 자동 추가
  - 검색창 초기화
  - 추가된 첫 글리프로 자동 이동
  - 이미 모두 존재하면 해당 세트 첫 글리프로 이동
  - 하단 상태 메시지 표시
- 도트 입력 캔버스 기본 표시 크기를 약 500px로 축소
- 낮은 화면에서는 약 440px까지 자동 축소
- 캔버스 전체를 한눈에 보기 쉬운 형태로 개선


## v10.5 — DotFont 프로젝트 파일
- 편집 중인 폰트를 로컬 파일로 저장 가능
- 전용 확장자 `.dotfont` 추가
- `.dotfont` 파일은 내부적으로 JSON 구조라 복구/호환이 쉬움
- 프로젝트 저장 대상:
  - 모든 글리프 도트 데이터
  - Grid 크기
  - 글리프별 자간
  - 가이드 설정
  - Ligature 규칙
  - 폰트 이름 / 스타일 / UPM
  - 현재 선택 글리프
  - Grid / Guide 표시 상태
- `프로젝트 불러오기` 버튼으로 사용자의 로컬 저장소에서 `.dotfont` 선택 가능
- 이전 JSON 프로젝트 호환을 위해 `.json` 파일도 불러오기 허용
- 브라우저 localStorage 자동저장은 그대로 유지

### 파일 예시
`MyPixelFont.dotfont`

`.dotfont`는 완성 폰트 파일이 아니라 DotFont 편집 프로젝트 파일입니다.
완성 폰트는 TTF/OTF 내보내기를 사용합니다.
